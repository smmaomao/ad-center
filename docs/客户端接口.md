1. 批量获取广告接口 (Get Ad List)接口类型：POST触发时机：App 启动时、缓存快用完时、或定时（如每隔 5-10 分钟）批量拉取广告素材并存储在本地。请求参数 (Request Body)：json{
  "ad_app_id": "app_10001",             // [必填] 广告后台分配给当前App的唯一ID
  "count": 5,                           // [必填] 期望批量拉取的广告素材数量
  "user_id": "user_abc_12345",         // [选填] 当前登录的业务用户ID（激励视频场景必传，用于发奖励对账）
  "adjust_adid": "adj_xyz_9988",       // [选填] Adjust设备标识（用于CPA多端归因追踪）
  "os": "ios",                         // [必填] 客户端操作系统：ios / android
  "ip": "192.168.1.100"                // [必填] 客户端IP（用于服务端频控、反作弊）
}
返回参数 (Response Body)：json{
  "code": 200,
  "msg": "success",
  "data": {
    "ad_list": [
      {
        "bid_id": "bid_20260908_0001",   // [核心] 本次广告下发的唯一交易ID，后续埋点必传
        "creative_id": "cr_90002",         // 素材ID
        "ad_style": "REWARDED_VIDEO",   // 广告样式：SPLASH(开屏)/REWARDED_VIDEO(激励视频)/INTERSTITIAL(插屏)/FEED(信息流)/BANNER(横幅)
        "material_type": "VIDEO",       // 素材类型：VIDEO(视频) / IMAGE(图片)
        "material_url": "https://xxx.com", // 素材下载/播放地址
        "width": 1080,                  // 素材分辨率宽度（px），便于客户端适配渲染
        "height": 1920,                 // 素材分辨率高度（px）
        "target_scene": ["GAME_OVER", "SHOP"], // 推荐场景标签。客户端可根据当前业务场景挑出最合适的素材
        "required_duration": 15,        // [针对激励视频] 必须连续观看满15秒，客户端才可以上报“视频播放完毕接口”
        "click_url": "https://landing.com{CLICK_ID}" // 落地页链接。带有{CLICK_ID}占位符，由客户端在拉起链接时替换
      },
      {
        "bid_id": "bid_20260908_0002",
        "creative_id": "cr_90005",
        "ad_style": "BANNER",
        "material_type": "IMAGE",
        "material_url": "https://xxx.com",
        "width": 640,
        "height": 100,
        "target_scene": ["MAIN_BOTTOM"],
        "required_duration": 0,
        "click_url": "https://landing.com{CLICK_ID}"
      }
    ]
  }
}


2. 曝光埋点接口 (Impression Track)接口类型：POST触发时机：当本地缓存的某个广告素材真正成功渲染在屏幕上，并被用户看到时立刻上报。作用：服务端收到后，触发广告系统的 CPM 扣费和展现统计。请求参数 (Request Body)：json{
  "bid_id": "bid_20260908_0001",       // [必填] 对应广告素材的唯一交易ID
  "ad_app_id": "app_10001",            // [必填] 应用ID
  "creative_id": "cr_90002",           // [必填] 素材ID
  "timestamp": 1774213460              // [必填] 客户端真实的曝光时间戳（秒）
}
返回参数：{"code": 200, "msg": "success"}

3. 点击埋点接口 (Click Track)接口类型：POST触发时机：当用户点击了广告素材、图片或“了解更多”按钮时触发。作用：服务端计费：触发 CPC 扣费。归因闭环（核心）：服务端会返回一个动态生成的全局唯一 click_id。客户端拿到此 click_id 后，必须把 click_url 中的 {CLICK_ID} 占位符替换掉，然后再拉起浏览器打开落地页。请求参数 (Request Body)：json{
  "bid_id": "bid_20260908_0001",       // [必填] 对应广告素材的唯一交易ID
  "ad_app_id": "app_10001",            // [必填] 应用ID
  "creative_id": "cr_90002",           // [必填] 素材ID
  "user_id": "user_abc_12345",         // [选填] 业务用户ID
  "adjust_adid": "adj_xyz_9988",       // [选填] 设备唯一标识
  "timestamp": 1774213465              // [必填] 点击时间戳
}
返回参数 (Response Body)：json{
  "code": 200,
  "msg": "success",
  "data": {
    "click_id": "clk_7788992233"       // [核心] 服务端生成的唯一点击流水ID
  }
}
💡 客户端特殊处理逻辑：客户端收到返回的 clk_7788992233 后，将该广告原有的 click_url：https://landing.com{CLICK_ID}动态替换为：https://landing.com替换完成后，再拉起系统浏览器或内置 WebView 打开该链接。


4. 视频播放完毕接口 (Video Complete)接口类型：POST触发时机：仅针对激励视频（REWARDED_VIDEO）样式。当用户观看视频的时间，达到或超过素材中规定的 required_duration 秒数（或视频自然播完）时，客户端触发此上报。作用：广告服务端接收并校验后，立刻触发异步 S2S 回调，通知对应的业务后端给该 user_id 发放奖励金币。请求参数 (Request Body)：json{
  "bid_id": "bid_20260908_0001",       // [必填] 对应广告素材的唯一交易ID
  "ad_app_id": "app_10001",            // [必填] 应用ID
  "creative_id": "cr_90002",           // [必填] 素材ID
  "user_id": "user_abc_12345",         // [必填] 拿奖励的业务用户ID
  "timestamp": 1774213495              // [必填] 播放完毕时间戳
}
返回参数：{"code": 200, "msg": "success"}
